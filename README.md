# E.E.S.T. N.º 5 "Amancio Williams" - Sitio institucional

Sitio estático de la Escuela de Educación Secundaria Técnica N.º 5 "Amancio Williams" de Mar del Plata.

## Características
- **100% estático:** HTML5, CSS3 y JavaScript.
- **Multi-página:** la Home es breve; el contenido se desarrolla en páginas internas.
- **Responsive** y con soporte de accesibilidad (teclado, `aria`, `prefers-reduced-motion`).

## Arquitectura
```text
/
├── index.html              # Home: portada + especialidades + pie
├── proyectos.html          # Línea de tiempo interactiva de hitos
├── expotec.html            # Exposición anual
├── especialidades/
│   ├── construcciones.html
│   ├── informatica.html
│   └── electronica.html
├── css/styles.css
├── js/script.js
└── img/
```
